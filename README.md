# 꽃놀이 고스톱

친구 두 명이 방 코드로 연결하거나 혼자 봇과 대전하는 금전 거래 없는 2인 맞고입니다. 화면은 GitHub Pages에서 제공하고 게임과 봇의 차례는 별도 서버에서 진행합니다.

봇 대전은 쉬움(먹을 기회를 놓치기도 하는 연습 상대), 보통(당장 얻는 패와 점수 고려), 어려움(족보 완성과 상대 득점, 공개된 패의 확률 고려) 중에서 선택합니다. 난이도는 새 봇 대전을 시작할 때 적용되며, 다시 하기를 누르면 같은 난이도가 유지됩니다. 기본 정산은 최종 점수 1점당 10코인입니다. 봇 승리는 쉬움 0.5배, 보통 1배, 어려움 2배를 적용해 1점당 각각 5·10·20코인을 받습니다. 봇 대전 패배는 난이도와 관계없이 1점당 10코인을 보유 코인까지만 차감하고, 친구 대전도 1점당 10코인입니다.

## 실행과 배포

`index.html`, `style.css`, `account.css`, `account.js`, `engine.js`, `app.js`, `assets/`를 공개 GitHub 저장소에 올리고 Settings → Pages에서 해당 브랜치와 루트(`/`)를 게시 소스로 지정합니다. 로그인한 뒤 한 명이 방을 만들고 6자리 코드를 다른 사람에게 전달합니다. 설치는 필요 없습니다.

두 플레이어는 HTTPS로 별도의 게임 서버에 접속합니다. 서버가 방·게임·계정·잔액을 관리하고 각 브라우저가 주기적으로 상태를 확인합니다. 게임 중 나가기는 기권으로 정산되며, 단순 연결 끊김은 로그인 후 이어서 할 수 있습니다. 방은 생성 후 6시간 뒤 만료됩니다. 방 코드는 신뢰하는 상대와만 공유하세요.

## 계정과 코인

아이디·닉네임·비밀번호로 가입하면 최초 한 번 1,000코인을 받습니다. 코인은 현금 구매·환전 없이 사용하는 가상 점수입니다. 비밀번호는 서버에서 소금값을 더해 PBKDF2로 해시하며 브라우저에는 로그인 토큰만 저장합니다. 로그인은 14일간 유지됩니다. 현재 이메일 인증과 비밀번호 찾기는 제공하지 않습니다.

친구 대전은 최종 점수(고와 배수 포함) 1점당 10코인이며, 봇 승리는 이 기본 정산액에 쉬움 0.5배·보통 1배·어려움 2배를 적용합니다. 기존 보유 코인·점수·전적과 완료된 정산 기록은 재계산하지 않습니다. 봇전 입장은 10코인 이상이어야 하고 봇에게 질 때는 잔액까지만 차감합니다. 친구 대전에서 잃은 정산액은 전액 차감하며 잔액이 음수가 된 부족분은 그 상대에 대한 빚입니다. 이후 얻는 코인은 오래된 빚부터 없애며 빚이 남은 동안 프로필에 `상대 닉네임의 노예`가 표시됩니다. 여러 상대에게 빚이 있으면 목록 전체와 가장 오래된 상대의 칭호를 보여줍니다.

승자는 최초 정산에서 이미 전체 코인을 받으므로, 빚을 없앨 때 같은 금액을 채권자에게 다시 지급하지 않습니다. 무승부는 코인 변동이 없고, 진행 중 나가기는 상대 최종 점수(최소 7점)를 1점당 10코인으로 기권 정산합니다. 한 계정은 한 방만 진행할 수 있으며 모든 정산은 서버에서 한 번만 처리합니다.

프로필에는 무승부까지 포함한 전체 대전 수와 승·패·무 전적이 표시됩니다. 본인 프로필에서 대출 원금 합계 3,000코인까지 빌릴 수 있습니다. 매번 빌린 금액의 10%를 이자로 한 번만 더하며 소수 코인은 올림합니다. 시간에 따라 추가 이자가 붙지 않고 원하는 때 보유 코인으로 상환합니다. 이자부터 갚고 실제 상환한 원금만큼 다시 빌릴 수 있습니다. 대출금은 기존의 음수 잔액과 상대방 빚을 먼저 메웁니다. 은행 대출은 자동 상환하지 않습니다.

## 선 정하기와 재대전

매 판 별도의 섯다 20장에서 두 장씩 뽑아 족보가 높은 사람이 먼저 둡니다. 광땡·땡·알리 등 일반 족보와 암행어사·땡잡이·구사 규칙을 적용하며 동점과 구사 재경기는 새로 뽑습니다. 맞고의 48장에는 영향을 주지 않습니다. 봇도 섯다에서 이기면 먼저 둡니다.

온라인 게임 종료 후 두 사람이 모두 ‘한 판 더’를 누르면 같은 방 코드와 접속을 유지한 채 새 판을 시작합니다. 새 판은 별도의 정산 번호를 갖고 선공도 다시 정합니다. 승리·패배·무승부 화면에 최종 점수와 실제 코인 증감을 크게 표시합니다. 낸 패, 뒤집은 패, 가져간 패, 뻑 등의 사건을 순서대로 보여주며 재접속이나 반복 조회로 같은 장면을 중복 재생하지 않습니다.

## 적용한 2인 맞고 규칙

48장 중 각자 10장과 바닥 8장으로 시작하고, 7점부터 고/스톱을 선택합니다. 총통 즉시 종료는 적용하지 않습니다. 처음 손패에 같은 월 네 장이 있어도 계속 진행합니다. 뻑·자뻑·쪽·따닥·싹쓸이, 피 가져오기, 흔들기·폭탄, 비삼광, 쌍피, 국진 열끗/쌍피 선택, 고도리와 홍단·청단·초단을 적용합니다. 폭탄을 내면 나중에 손패 대신 더미를 뒤집는 기회가 2번 생깁니다. 고 횟수만큼 점수를 더한 뒤 3고부터 배수를 적용하고, 광박·피박·멍따·고박도 점수에 적용하며 돈을 사용하지 않습니다. 피박은 상대 피 1~7장일 때 적용합니다. 마지막 차례의 쪽·따닥·싹쓸이는 제외하며, 끝까지 스톱이 없으면 나가리입니다.

지역별 규칙 차이를 줄이기 위해 이 버전은 조커·보너스패, 첫뻑·삼뻑 특별 보너스, 다음 판 나가리 배수는 적용하지 않습니다. 같은 달에 흔들고 폭탄을 내더라도 배수는 한 번만 적용합니다. 화면의 최근 차례와 '낸 패 자세히'에서 손에서 낸 패와 더미에서 뒤집은 패를 구분할 수 있습니다.

SVG 내용은 변경하지 않고 파일명만 바꿨습니다. 개별 파일 출처는 `assets/cards/verification.json`에 기록되어 있습니다.

Empty surface only, no playing cards, no objects, no hands, no text, no logos, no borders. Wide landscape framing, realistic and unobtrusive.”
